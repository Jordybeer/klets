# Klets

Klets is een speelse webapp voor korte, passende inspiratie binnen een vrijwillige volwassen D/s-dynamiek. Een bewegende, geklede 3D-mascotte geeft één idee per tik; context en toon bepalen welke ideeën passen.

Dit project begint bij een samenhangend ontwerp. De eerste versie wordt een React-app met lokale voorkeuren, favorieten en een optionele momentcheck.
